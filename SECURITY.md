# Security Policy

## Reporting a vulnerability

If you discover a security issue in this repository, report it privately to
**anthony@etherealogic.com**.

Do not open public issues for security-sensitive findings.

## Scope

This repository is a local demonstration of a distribution-stability control
pattern. It ships deterministic sample data and does not include credentials,
production data, or live Databricks secrets.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
