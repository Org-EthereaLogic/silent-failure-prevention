All notable changes to this project will be documented in this file.

## [0.1.0] — 2026-03-31

### Added

- Entropy-based drift detection across five monitored business columns
- Baseline snapshot model for trusted Silver loads
- Release-gate evaluation driven by `config/kpi_thresholds.json`
- Provenance envelope builder for audit-ready control output
- Deterministic baseline and drifted sample datasets
- Local CLI runner and Databricks-style notebook walkthrough
- Technical approach documentation and repository metadata files
- 50-test suite covering entropy, baseline, drift, gates, provenance, and integration behavior
